> 票价与开放时间以"苏州园林旅游"公众号和各馆官网为准。

# 行前 Checklist

- [ ] **苏博预约（头等大事）**：提前 7 天、早 8 点放票，"苏州博物馆"公众号实名预约，免费，周一闭馆。本馆（东北街，贝聿铭设计）就在拙政园隔壁。
- [ ] 高铁买到**苏州站**（紧贴古城），别买苏州北站（离古城远）。
- [ ] 酒店定在**观前街—平江路一带**（临顿路地铁站附近），三天步行+地铁+偶发网约车即可。
- [ ] 天气：11 月下旬约 5–15°C，阴多雨。薄羽绒、伞、走长路的鞋（石板路教训人）。
- [ ] 园林门票都能在"苏州园林旅游"或"君到苏州"公众号提前买，淡季现场买也行，提前买省心。

# Day 1 ｜ 古城东线：园林之王与光影博物馆

| 时间 | 安排 |
| --- | --- |
| 07:30 | **拙政园开门即进**。第一批入园，旅行团还在吃早餐。晨光加空园，是全天唯一配得上"中国园林之母"的时刻。 |
| 10:30 | 出园步行 3 分钟，**苏州博物馆本馆**（已预约）。贝聿铭 85 岁封山之作：白墙灰瓦的几何光影本身就是展品，摄影重头戏留在这里。 |
| 12:30 | 午饭：裕兴记或同得兴，一碗苏式**头汤面**（焖肉、爆鱼浇头）。 |
| 14:00 | **狮子林**。假山迷宫钻 40 分钟，比拙政园好玩，专治午困。 |
| 15:30 | **平江路**。喝茶、慢逛、看河。想听评弹，提前订**琵琶语评弹茶馆**的场次（《声声慢》出处）。 |
| 18:00 | 平江路夜景，晚饭就地解决，哑巴生煎当加餐。 |
| 晚 | 回酒店。有余力记一笔：中张家巷的中国昆曲博物馆（免费），可列为次日备选。 |

# Day 2 ｜ 西线：吴王的剑，夜泊的钟

| 时间 | 安排 |
| --- | --- |
| 08:30 | **虎丘**。"到苏州不游虎丘，乃憾事也"——苏轼。剑池相传是吴王阖闾的墓门，三千名剑陪葬；云岩寺塔是中国的第一斜塔。留 2 小时。 |
| 11:00 | **寒山寺 + 枫桥景区**。张继"姑苏城外寒山寺，夜半钟声到客船"的原址。庙不大，40 分钟，重点是站枫桥上望运河。 |
| 12:30 | 午饭就近，或直接去**西园寺**吃素面（观音面，寺里猫比游客多）。 |
| 14:00 | **留园**。四大名园之一，以建筑空间的回环变换见长；镇园之宝冠云峰，相传是宋徽宗"花石纲"的遗物。1.5 小时。 |
| 16:30 | 回酒店歇脚。三天里唯一的中场休息，别省。 |
| 17:30 | **山塘街**。白居易任苏州刺史时主持开凿的山塘河，号称七里山塘。日落前到，先吃碗糖粥，天黑亮灯后上通贵桥拍全景——灯笼映水，苏州夜景的封面。 |

# Day 3 ｜ 二选一

**方案 A：天平山**（行程恰逢 11 月中下旬—12 月初时选这个）

中国四大赏枫胜地之一，此时正是红枫季。山不高，枫红、银杏、碧水一层叠一层，半天爬山半天拍照，比城里园林多一分野趣。带干粮。

**方案 B：城内慢游**（其他时段，或不想爬山）

- 上午 **网师园**：苏州最小的名园，也是最精的。一拳代山、一勺代水。
- 中午 **沧浪亭 + 可园**（门对门）：沧浪亭是苏州现存最老的园林（北宋苏舜钦），未入园先见一泓水，格局独一份。
- 下午 **艺圃**：藏在文衙弄深处的明代小园，文徵明曾孙文震孟曾居于此。游客稀少，在池边茶室喝杯茶，是三天里最像"住下来"的一刻。
- 傍晚 **金鸡湖**（地铁直达）：现代天际线加月光码头日落，与前两日构成古与今的对位。下雨备选：诚品书店。

想去水乡古镇，把方案 B 换成**同里**一日（地铁 4 号线同里站，比周庄清净，生活气重）。

# 吃单（按优先级）

1. **头汤面**：同得兴（嘉馀坊店）或裕兴记。早上去，头一锅汤最清。
2. **阳澄湖大闸蟹**：11 月正当季，清蒸，配姜醋，别点花哨做法。
3. **哑巴生煎**：临顿路，底脆汁烫，小心咬。
4. **糖粥**与**海棠糕**：平江路、山塘街沿线见摊就买，趁热。
5. **松鼠桂鱼**：松鹤楼或得月楼。酸甜口，两个人一条刚好。

# 摄影备忘

- 拙政园和苏博都排在开门时段——旅行团到场之前，光线和空园不可兼得之外，这是唯一能兼得的窗口。
- 山塘街的封面照在通贵桥上，日落后 20 分钟的蓝调时刻去。
- 雨天别收相机：湿石板反光，园林的第二种样子。
